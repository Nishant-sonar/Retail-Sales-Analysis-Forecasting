# 📊 Retail Sales Analysis & Forecasting

## 📌 Project Overview
This project focuses on analyzing retail sales data to uncover trends, patterns, and key business insights. It also includes forecasting future sales using time series techniques to support data-driven decision-making.

---

## 🎯 Objective
- Analyze historical sales data to identify trends and seasonality  
- Perform exploratory data analysis (EDA)  
- Build a forecasting model to predict future sales  
- Generate actionable insights for business improvement  

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)  
- Matplotlib, Seaborn, Plotly  
- Time Series Analysis  
- Jupyter Notebook  

---

## 📂 Dataset
- Global Superstore retail dataset  
- Contains order-level data including sales, category, region, and time-based features  

---
